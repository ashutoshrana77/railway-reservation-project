# Railway Reservation System

A responsive project showcase for a Java OOP mini/major project by **BinaryBrain0100**.

## About

The site introduces the railway reservation system concept, its real-world applications, and the learning benefits of building it with Java object-oriented programming. The ticket panel is a visual UI concept only: it is **not connected to a live railway booking service** and does not create reservations.

## Run locally

Open `index.html` in a modern browser. The site is static and has no package installation or backend requirement.

## Deployment

Hosted through Vercel from the public GitHub repository `ashutoshrana77/railway-reservation-project`.
