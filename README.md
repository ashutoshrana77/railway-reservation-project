# Trackline — Railway Reservations

A polished passenger-facing train search and reservation demo.

## What you can explore

- Search sample train services by departure, destination, travel date, and class.
- Browse popular routes, indicative fares, sample timings, and availability.
- Preview a sample reservation by entering passenger details.
- Use the responsive layout on desktop and mobile.

All train data, availability, fares, and confirmations are examples only. No real ticket is booked and no payment is collected.

## Run locally

Open `index.html` in a modern browser.
